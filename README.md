## About

I'm a BCA student who learns by building. My projects so far include a SIEM with MITRE ATT&CK-mapped detection rules, a client-side password inspector, and a privacy-awareness demo. I test my detection work against a Kali Linux and Metasploitable lab.

## Featured Projects

### [PySIEM](https://github.com/bibashthapa143/pysiem) <sub>· In progress</sub>
A lightweight SIEM in Python. It parses SSH auth logs, stores normalized events in SQLite, runs YAML detection rules mapped to MITRE ATT&CK, deduplicates alerts, and serves an analyst dashboard.
`Python` · `FastAPI` · `SQLite` · `React` · `pytest` &nbsp;|&nbsp; [Live demo](https://pysiem.vercel.app)

### [Keyguard](https://github.com/bibashthapa143/Keyguard)
A client-side password security inspector. It measures entropy with `zxcvbn`, estimates crack times across four attack scenarios, checks breach exposure, and generates passwords and passphrases. Only the first 5 characters of the SHA-1 hash leave the browser (k-anonymity with Have I Been Pwned).
`Next.js` · `JavaScript` &nbsp;|&nbsp; [Live demo](https://password-breach-checker-three.vercel.app)

### [whoami-next](https://github.com/bibashthapa143/whoami-next)
A privacy-awareness demo showing what a website can infer about a visitor from their public IP and browser metadata, with an exposure score and charts.
`Next.js` · `React` · `Tailwind CSS` · `Chart.js`

### [nmap_wrapper](https://github.com/bibashthapa143/python/tree/main/projects/nmap_wrapper) <sub>· Learning project</sub>
A command-line tool that runs Nmap and shows only the open ports, with `--target`, `--ports` and `--save` options.
`Python`
