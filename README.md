## About

I like understanding how systems work by building them, and security is where that curiosity keeps leading me. My projects so far include a log-analysis system, a wrapper around Nmap, a password breach checker, and a demo of what websites can infer about their visitors.

**Currently building:** [PySIEM](https://github.com/bibashthapa143/pysiem), a lightweight SIEM in Python.

---

## Projects

| Project | What it does | Built with |
|---|---|---|
| [**PySIEM**](https://github.com/bibashthapa143/pysiem)<br/>*In progress* | Lightweight SIEM: log parsing and normalization, SQLite storage, YAML-driven detection rules mapped to MITRE ATT&CK, alert deduplication and a web dashboard | Python, FastAPI, SQLite |
| [**Password Breach Checker**](https://github.com/bibashthapa143/password-breach-checker-)<br/>[Live demo](https://password-breach-checker-three.vercel.app) | Checks password strength and breach exposure. The password never leaves the browser: only the first 5 characters of its SHA-1 hash are sent to the Have I Been Pwned API (k-anonymity) | Next.js, JavaScript |
| [**whoami-next**](https://github.com/bibashthapa143/whoami-next) | Privacy-awareness demo showing what a website can infer about a visitor from their public IP and browser metadata, with an exposure score and charts | Next.js, React, Tailwind CSS, Chart.js |
| [**nmap_wrapper**](https://github.com/bibashthapa143/python/tree/main/projects/nmap_wrapper) | Command-line tool that runs Nmap and shows only the open ports (`--target`, `--ports`, `--save`). A learning project | Python |
| [**OOP in Java**](https://github.com/bibashthapa143/oop-in-Bibash_java) | Class work and practice for object-oriented programming | Java |

More in the [repositories tab](https://github.com/bibashthapa143?tab=repositories).
